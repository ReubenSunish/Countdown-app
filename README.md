# Countdown Timer & Notification App — Node.js & Asynchronous JavaScript

A set of small standalone Node.js programs exploring core Node.js concepts and asynchronous JavaScript, built around a "Countdown Timer & Notification App" theme for coursework.

## Tasks Covered

| File | Task |
|---|---|
| `task1_countdown.js` | Node.js Development Setup & Running Node.js Files |
| `task2_countdown.js` | Understanding How Node.js Works & Node.js Architecture |
| `task4_countdown.js` | NodeJS REPL Introduction |
| `task5_countdown.js` | Node Process Object, Command Line & Terminal I/O |
| `task8_countdown.js` | Asynchronous Programming & Callback Functions |
| `task9_countdown.js` | Node Timers & Global Objects |
| `task10_countdown.js` | JavaScript Promises — Introduction, Detail & Revisited |
| `task11_countdown.js` | Try/Catch Error Handling & Async-Await Concepts |
| `task13_countdown.js` | Callback Examples & the Event Loop, Job Queue |
| `task14_countdown.js` | Recursive Functions, Event Loop Execution Flow & EventEmitter |

## Running

Each file is standalone. Run any of them with Node.js:

```bash
node task1_countdown.js
```

`task5_countdown.js` takes a countdown duration as a command-line argument and reads terminal input, so run it like this:

```bash
node task5_countdown.js 15
```

While it's counting down, type `cancel` and press Enter to stop it early.
